Privacy

Local first.

The app
Companion memory and preferences are stored locally. The repository documents zero analytics SDKs, ad trackers or background telemetry.
On-device
Magic Eraser runs with Apple Vision. Nothing is uploaded.
Optional network use
Open-Meteo weather sync, AI sprite generation through a configured provider, GitHub Releases update checks. Discord Rich Presence talks to the local Discord socket, and Spotify and Apple Music status is read through AppleScript on your Mac.
Payments
Not live. When enabled, payment goes through an external hosted provider and license activation involves license data.
This website
No analytics, cookies, tracking pixels or forms. The Download page asks GitHub’s public API for release data from your browser, so GitHub sees that request.

This is a plain-language summary, not legal advice. See SECURITY.md.
