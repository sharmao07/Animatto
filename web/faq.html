FAQ

Questions, answered.

Is Animatto Mac only?

Yes. It is a native macOS app: macOS 14.6 or later, Apple Silicon and Intel.

Does the aquarium need its own app window?

Aquarium Mode covers the Clock, Weather, Calendar, and other Apple desktop widgets. Companions you launch from the library stay companions.

Why does macOS show a security warning?

Some releases are not notarized. Control-click the app, choose Open and confirm once.

Where do I download Animatto?

From GitHub Releases, or from the Download page on this website. Both point at the same files. There is no Mac App Store version.

How do I update?

Animatto checks GitHub Releases. You can also download the newer file from this website.

Does it collect telemetry?

The repository states there are no analytics SDKs, ad trackers or background telemetry. See Privacy for optional network features.

Does Magic Eraser upload images?

No. It uses Apple’s Vision framework on your Mac.

Does it work offline?

Core companion features do. Weather sync, AI generation, Discord and update checks use the network.

How much does Animatto cost?

The published app is free under Apache-2.0. Checkout is not live.

Are purchases live?

No. The pricing page does not link to checkout, and production payments stay off.

Can I use my own characters?

You can import packs you own. Respect their license; Animatto only bundles its original artwork.
