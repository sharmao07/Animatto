Aquarium

The widgets become the tank.

Aquarium is a cover for the desktop widgets you already have. Launching a companion is a different button.

Desktop Widgets Transformed into Aquariums
In-Place Transformation
Aquarium Mode Control Dashboard

In-Place Transformation, Not Another Window

When Aquarium Mode is activated, Animatto detects active macOS desktop widgets (Clock, Weather, Calendar, Battery) via Quartz Window Services and overlays living aquatic tanks directly on top of their frames.

  • Desktop PinnedAquariums use the macOS desktop window tier with stationary Space assignment, so they never follow into full-screen apps.
  • Companion IndependenceCompanions launched from your library remain companions. They wander over the top of the tank without being converted into fish.
  • Instant RestorationTurning off Aquarium Mode directly dismisses the covers with zero glitching or sprite flashing.

Aquatic Species Roster

Each species features distinct buoyancy models, swimming velocities, and interaction behaviors.

Finny

Golden Sunfin

Amber-gold pelagic cruiser with flowing dorsal fins that swims gracefully through middle depths (65–140 pt/s).

Pip

Pygmy Puffer

Curious spotted puffer with fluttering fin physics, hovering buoyancy, and playful boundary bounces (50–110 pt/s).

Glow

Ghost Tetra

Translucent bioluminescent tetra swimming in coordinated groups using Reynolds flocking algorithms (70–160 pt/s).

Barnaby

Hermit Crab

Moss-covered crustacean with benthic negative buoyancy that scuttles realistically across bottom gravel (35–80 pt/s).
