    Install
    1. Open the DMG and drag Animatto into Applications.
    2. Open Animatto.
    3. If macOS warns about an unidentified developer, Control-click the app, choose Open, then confirm.
    Some releases may be ad-hoc signed and not notarized. Never disable Gatekeeper globally. To check a download run shasum -a 256 Animatto.dmg and compare it with a checksum published on the release. If none is published, the page says so.
